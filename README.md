# Issa Alexandre Tagro

I'm building **Overlink**, a bridge between ChatGPT and Windows PCs. It connects an AI assistant to local tools for files, commands, browsers and supported applications, with permissions and visible action results.

I'm based in Germany and have been training as a **Fachinformatiker für Anwendungsentwicklung** (application development apprentice) since August 2026. I use Claude Code and Codex in my development workflow, with a focus on integrations, debugging and testing.

## Projects

### [Overlink](https://github.com/useralx01/Overlink-showcase)

My main project. The development setup has used two personal Windows computers. The public repository explains the architecture and current scope; the implementation is private. Demo videos and a technical walkthrough are available on request.

### Licht

An Electron workspace prototype for AI conversations, projects and work on a PC. Started in October 2026; reliable continuity and coordination across sessions are still in development.

### [PocketLM](https://github.com/useralx01/PocketLM)

An earlier, currently inactive local inference project: Python/Torch runtime experiments, native C++ helpers, disk-backed weight streaming and a managed llama.cpp/GGUF backend. The repository separates implemented paths, fixture checks and historical benchmark notes.

### [Hermes / Veyra](https://github.com/useralx01/Hermes)

A customized distribution of Nous Research's Hermes Agent, with PocketLM integration and local desktop tooling. The repository preserves upstream credit and describes the additions.
